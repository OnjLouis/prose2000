Prose 2000

Prose 2000 brings the vintage Telesensory Systems speech synthesizer to modern NVDA. It runs the original firmware in a compact, isolated host and sends the resulting audio through NVDA's selected output device. No original speech hardware or MAME installation is required.

Using Prose 2000

  1. Open NVDA's Select Synthesizer dialog with NVDA+Control+S.
  2. Choose Prose 2000.
  3. Select OK.

Rate, Rate Boost and Volume are available through NVDA's speech settings and synthesizer settings ring.

Updates

Prose 2000 checks its GitHub releases for updates once a day. To check manually, open NVDA's Tools menu and choose Check for Prose 2000 updates. Update checks run in the background and do not interrupt speech.

Reliability

The emulator runs outside NVDA. Cancelling speech stops queued audio immediately, and an unresponsive speech host can be restarted without taking down NVDA itself.
