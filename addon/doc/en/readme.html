Prose 2000

Prose 2000 brings the vintage Telesensory Systems speech synthesizer to modern NVDA. It runs the original firmware in a compact, isolated host and sends the resulting audio through NVDA's selected output device. No original speech hardware or MAME installation is required.

Using Prose 2000

  1. Open NVDA's Select Synthesizer dialog with NVDA+Control+S.
  2. Choose Prose 2000.
  3. Select OK.

Rate, Pitch and Volume are available through NVDA's speech settings and synthesizer settings ring. A value of 50 selects the original default rate and pitch, while 100 selects the original full volume. These settings use controls built into the original Prose firmware, so no separate audio-processing add-on is required.

The supplied firmware contains one English male voice. Prose 2000 does not provide selectable voices or variants.

Updates

Prose 2000 checks its GitHub releases for updates once a day. To check manually, open NVDA's Tools menu and choose Check for Prose 2000 updates. Update checks run in the background and do not interrupt speech.

Reliability

The emulator runs outside NVDA. Cancelling speech stops queued audio immediately, and an unresponsive speech host can be restarted without taking down NVDA itself.

Changes

1.1.0

  • Replaced software rate and volume processing with the original firmware's native Rate, Pitch and Volume controls.
  • Added continuous pitch adjustment, with the original pitch at NVDA 50.
  • Documented the single supplied voice and the supported firmware settings.
  • Added complete source and firmware attribution.
  • Added standalone build and usage documentation for the diagnostic prose_cli tool. Closes Issue #1.

1.0.0

  • Added the first public NVDA driver for Prose 2000.
  • Added native PCM streaming through NVDA.
  • Added speech cancellation, pause and host recovery.
  • Corrected scratchy sibilants by synchronising audio generation with the firmware's safe synthesis boundary.
  • Added automatic and manual GitHub update checks.
  • Added direct rendering support through SoundWave 1.2.1 and later.
